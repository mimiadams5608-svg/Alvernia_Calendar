
# Test Log – Academic Calendar

## 1. Phone Testing

**Test:** Mobile calendar navigation

**What was tested:** Whether the calendar navigation controls display correctly on a phone-sized screen.

**Steps performed:**
1. Opened the academic calendar using a phone-sized screen.
2. Navigated through different months.
3. Checked whether the month title and navigation arrows remained visible.

**Expected result:** The month title and navigation arrows should remain visible, properly spaced, and should not overlap.

**Actual result:** Longer month names are covered by the next-month arrow on smaller screens.

**Status:** FAIL

**Issue identified:** The month title does not have enough space on smaller screens, causing it to overlap with the next-month arrow.

**Revision needed:** Adjust the mobile navigation layout so longer month names fit without overlapping the navigation arrows.
