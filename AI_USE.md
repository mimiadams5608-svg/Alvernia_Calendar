AI Usage Documentation
Project: Alvernia University Academic Calendar
Developer: Samiyyah Adams
Date: November 2026

1. Purpose of AI Usage
Artificial Intelligence (AI) tools were used as development assistance during the creation and improvement of the Alvernia University Academic Calendar.

AI was used to help with coding, troubleshooting, design improvements, accessibility considerations, and testing guidance.

The purpose of using AI was to support the development process, improve understanding of HTML, CSS, and JavaScript, and help identify potential issues.

AI was used as an assistant, not as a replacement for the developer's involvement or decision-making.

2. How AI Was Used
AI assistance was used in the following areas:

HTML Development
Assistance organizing page structure and HTML elements.
Reviewing the structure of calendar sections and navigation.
Helping identify and correct markup issues.
CSS and Visual Design
Assistance improving the calendar's visual appearance.
Developing responsive layouts for desktop and mobile screens.
Adjusting spacing, alignment, typography, and navigation.
Troubleshooting overlapping elements and mobile layout problems.
JavaScript Functionality
Assistance troubleshooting calendar functionality.
Reviewing month navigation and date display logic.
Supporting category filtering.
Improving event modal functionality.
Troubleshooting interactive elements.
Accessibility
Guidance on keyboard accessibility.
Assistance with keyboard focus behavior.
Reviewing event modal accessibility.
Supporting keyboard navigation for calendar controls and mobile menus.
Troubleshooting
Used AI to help identify potential coding errors.
Reviewed suggested corrections before adding them.
Tested changes in the browser to confirm that they worked as expected.
3. Developer Responsibilities
Although AI provided coding assistance, the developer remained responsible for reviewing and evaluating the suggested changes.

The developer:

Provided the original project code and requirements.
Reviewed AI-generated code suggestions.
Decided which changes to implement.
Integrated changes into the existing project.
Tested the calendar's functionality.
Identified issues that required additional improvements.
Confirmed whether implemented changes worked correctly.
AI-generated suggestions were not automatically assumed to be correct.

4. Testing and Verification
The calendar underwent 13 user-confirmed tests on November 8, 2026.

Testing included:

Keyboard navigation.
Opening and closing calendar event modals.
Month navigation.
Category filtering.
Today button functionality.
Mobile menu navigation.
Browser zoom and responsive layout.
Small phone screen compatibility.
Mobile event modal functionality.
Landscape phone orientation.
Testing Result: 13 tests passed, with no reported failures.

See test_logs.md for the complete testing record.

5. Limitations of AI Assistance
AI-generated code and recommendations may contain errors, inconsistencies, or suggestions that do not fit the project's requirements.

For this reason:

Suggested code was reviewed before implementation.
Existing working functionality was preserved when making updates.
Changes were tested in the browser.
Additional testing may still be necessary across different browsers, devices, and accessibility tools.
AI assistance does not guarantee that the application is completely error-free or fully accessible.

6. Transparency Statement
AI tools were used throughout portions of the development process to assist with coding, troubleshooting, design, and testing.

The developer reviewed the suggestions, made implementation decisions, and verified the functionality of the changes through testing.

This documentation is provided to maintain transparency about the use of AI during the development of the Alvernia University Academic Calendar.
